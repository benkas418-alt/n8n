# Structures de persuasion : quand et comment les employer

Les formules ci-dessous sont des outils d'organisation, pas des lois psychologiques ni des garanties de conversion.

## AIDA
- Attention : ouvrir sur le besoin, la question ou la promesse.
- Intérêt : expliquer la situation et les éléments pertinents.
- Désir : rendre le bénéfice concret et crédible.
- Action : demander une étape claire.

À utiliser pour les publicités, pages courtes et messages qui accompagnent une offre.

## PAS
- Problème : nommer une difficulté réellement vécue.
- Agitation : montrer ses conséquences sans dramatisation.
- Solution : expliquer le mécanisme qui aide à la résoudre.

À utiliser quand le public connaît déjà le problème. Ne crée pas de peur artificielle.

## Avant – Après – Passage
- Avant : situation actuelle du client.
- Après : situation améliorée, réaliste et souhaitable.
- Passage : mécanisme concret permettant de progresser.

À utiliser pour les services, transformations et storytelling commercial.

## FAB
- Feature / caractéristique : ce que le produit possède ou fait.
- Advantage / avantage : ce que cela permet.
- Benefit / bénéfice : pourquoi cela compte dans la vie du client.

À utiliser pour les fiches produits, argumentaires et catalogues.

## Problème – Solution – Preuve – Action
1. Situation concrète.
2. Réponse proposée.
3. Démonstration, preuve ou élément vérifiable.
4. CTA.

À utiliser pour les vidéos et publications sociales orientées commande.

## Objection – Réponse – Réassurance – Action
1. Identifier l'objection principale.
2. Répondre avec un fait ou une explication.
3. Réduire le risque perçu avec une condition claire.
4. Donner la prochaine étape.

À utiliser pour les prospects hésitants et les pages FAQ/vente.

## Offre – Valeur – Conditions – Action
1. Décrire l'offre.
2. Expliquer la valeur réelle.
3. Afficher prix, période, exclusions et modalités pertinentes.
4. Demander l'action.

À utiliser pour les promotions et offres limitées réellement vérifiables.

## Choisir le bon framework

| Situation | Structure de départ |
|---|---|
| Le public découvre le problème | AIDA ou problème-solution-preuve-action |
| Le public ressent déjà le problème | PAS mesuré |
| Il faut illustrer une transformation | Avant-après-passage |
| Le produit a plusieurs caractéristiques | FAB |
| La vente bloque sur une objection | Objection-réponse-réassurance-action |
| L'offre est promotionnelle | Offre-valeur-conditions-action |

## Message de vente en une phrase

Utilise cette structure pour clarifier la proposition avant la rédaction longue :

« Pour [public], [offre] aide à [bénéfice] grâce à [mécanisme/preuve], contrairement à [alternative pertinente si démontrée]. »

Si cette phrase ne peut pas être complétée sans inventer, les informations de départ sont insuffisantes : formule les hypothèses et indique ce qu'il faut vérifier.
