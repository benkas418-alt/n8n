# Protocole de tests et d'analyse PitUp

## 1. Chaque vidéo doit tester une hypothèse

Exemples :
- « Une situation que beaucoup de personnes ont vécue génère plus d'envois qu'une présentation de fonctionnalité. »
- « Une ouverture visuelle avec une réaction humaine retient mieux qu'une capture d'écran. »
- « Un script de 20 secondes est plus regardé jusqu'au bout qu'une version de 35 secondes pour cette idée précise. »
- « Une accroche qui présente le problème avant le nom PitUp amène plus de visites de profil. »

Une hypothèse n'est pas un fait. La tester et documenter le résultat.

## 2. Indicateurs

Suivre, lorsque la plateforme les fournit :
- vues / portée ;
- temps moyen de visionnage ;
- durée de vidéo ;
- taux de visionnage complet ;
- rétention aux premières secondes ou courbe de rétention ;
- relectures (avec prudence, selon la définition de la plateforme) ;
- partages / envois ;
- likes ;
- commentaires ;
- enregistrements ;
- visites du profil ;
- nouveaux abonnés attribuables ;
- clics, messages, téléchargements et commandes si mesurables.

Instagram : surveiller particulièrement le temps de visionnage, les likes par portée et les envois par portée, en gardant à l'esprit que les indicateurs disponibles varient selon les comptes et les interfaces.

TikTok : surveiller le temps de visionnage, le taux de complétion, les partages, les commentaires, les sources de trafic et les indicateurs de recherche disponibles.

Ne compare pas directement des métriques de plateformes différentes si leurs définitions ne sont pas identiques.

## 3. Calculs pratiques

Lorsque les données sont disponibles :
- **durée moyenne relative (%)** = temps moyen de visionnage ÷ durée de la vidéo × 100 ;
- **taux de partage** = partages ÷ portée (ou vues si la portée n'est pas disponible, mais garder le même dénominateur pour toutes les comparaisons) ;
- **taux de visite du profil** = visites du profil attribuées ÷ portée ;
- **taux d'action commerciale** = actions commerciales attribuées ÷ visites pertinentes.

Ne mélange pas les dénominateurs. Indique la formule et la source des chiffres.

## 4. Diagnostic

- chute immédiate : première image, première phrase ou clarté du sujet à revoir ;
- bon démarrage puis chute rapide : contexte trop long, répétition ou absence de progression ;
- bonne rétention, peu de partages : vidéo regardable mais pas assez transmissible, utile ou relatable ;
- beaucoup de partages mais peu de visites de profil : contenu divertissant, lien à la marque trop faible ;
- beaucoup de visites de profil mais peu d'actions : promesse, profil, offre ou parcours de commande à clarifier ;
- beaucoup de commentaires sans visionnage : le sujet peut susciter le débat, mais le hook ou le montage ne retient peut-être pas.

Ce sont des diagnostics possibles, pas des certitudes. Vérifier les données et le contexte avant de conclure.

## 5. Test A/B des hooks

Pour un même concept, faire deux ou trois ouvertures réellement différentes :
- version A : identification ;
- version B : surprise ;
- version C : question ou démonstration.

Garder le reste du montage aussi proche que possible. Si tout change en même temps, on ne saura pas ce qui a provoqué l'écart.

Ne republie pas en boucle des doublons identiques. Utilise les options de test de la plateforme quand elles existent et respecte les règles de chaque application.

## 7. Rythme d'analyse

- premier contrôle : environ 24 h ;
- deuxième contrôle : environ 72 h ;
- bilan : après 7 jours, ou plus tard si les vues continuent d'évoluer ;
- revue hebdomadaire : identifier les formats à répéter, modifier ou arrêter.

Ces délais sont des jalons de travail et non des fenêtres officielles de classement.

## 8. Règles d'interprétation

- Une vidéo virale isolée ne valide pas un format à elle seule.
- Comparer des vidéos de même type, de durée proche et de maturité comparable.
- Utiliser la médiane et examiner plusieurs publications.
- Ne pas supprimer un concept uniquement parce qu'une seule exécution a échoué.
- Refaire le format avec une nouvelle histoire, un autre hook ou une meilleure preuve.
- Conserver les résultats négatifs : ils évitent de répéter les mêmes erreurs.
