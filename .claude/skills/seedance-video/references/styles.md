# Visual styles

Name the style in the first line and keep it identical across shots. For 2.0, also set
`genre` when it fits (`action`, `horror`, `comedy`, `noir`, `drama`, `epic`).

| Style | Key words that work | Watch out |
|---|---|---|
| Cinematic film | anamorphic, shallow depth of field, film grain, motivated light, slow dolly | One move per shot; avoid "epic" with no concrete action |
| Action / fight | wide master shot, clear geography, one strike per beat, impact frame, dust | Fast limbs distort: short shots, simpler choreography |
| Horror / noir | low key light, hard shadows, practical lights, slow push-in, silence then sound | Keep it suggestive; no gore |
| Anime | cel-shaded, clean line art, speed lines, dramatic sky, held poses, smear frames | Keep character design fixed with a reference sheet |
| Cartoon / 2D | flat colours, thick outlines, squash and stretch, bouncy timing | Simple backgrounds animate better |
| 3D CGI | subsurface scattering, soft global illumination, stylised proportions, studio lighting | State "rendered 3D animation", or it drifts to photoreal |
| Music video | beat-synced cuts, light pulses on the beat, performance + abstract inserts | Attach the track as `audio_references` for sync |
| Real estate / interiors | steady gimbal walk-through, golden hour, wide lens 16–24 mm, windows bright | No distortion of rooms; never show features the property does not have |
| Documentary / street | handheld, natural light, real textures, candid people | Respect real places and people; no fake events |

## Camera moves (one per shot)

push-in · pull-back · orbit (left/right, 90°/180°/360°) · crane up / down · tracking
(follow, lead, side) · pan / tilt · whip pan · handheld · static locked-off · top-down ·
Dutch angle · dolly zoom (vertigo) · FPV drone.

## Lens and framing

macro (texture) · 35 mm (natural, street) · 50 mm (portrait) · 85 mm (close-up, background
blur) · wide 16–24 mm (space, interiors) · telephoto (compressed city, sport) ·
extreme close-up / close-up / medium / wide / establishing.
